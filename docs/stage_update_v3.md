本更新では、CHaserのチュートリアルステージを再構成し、全54ステージ・10グループを作成しました。

個別ステージのマップ、使用ブロック、クリア条件、解答例、HOTの行動プログラムなどは、[チュートリアルステージ一覧・レビュー](./stage_review_v3.html) にまとめています。本ページでは、ステージ全体の構成と設計方針、主な変更点を説明します。

---

## 今回の設計方針

今回のチュートリアルでは、少しずつ新しい要素を追加して学べる構成を目指しました。

特に、次の点を重視しています。

- D2までで、最低限の対戦プログラムを作れるようにする。
- その後のステージで、LOOKやSEARCHなど、今後使用する機能の理解につながる考え方を扱う。
- 次のステップで増えるブロックは、原則として1個または2個程度に抑える。
- ステージごとに難易度を設定し、段階的に難しくなる構成にする。
- 実際の対戦で必要な知識とプログラミングに必要なパズル的思考を分けてグルーピングする。

ブロックセットを細かく分割したため、現時点では一部の名称が暫定的です。今後、実際の利用状況を見ながら整理します。

## ステージグループ

| グループ | 主な内容 | 目的 |
| --- | --- | --- |
| A | 条件なし | 順次処理や基本操作に慣れる。 |
| B | 壁判定・1条件 | 壁を確認しながら行動する条件分岐を学ぶ。 |
| C | アイテム・そうでなくもし | アイテムの取得と、条件に応じた行動の切り替えを学ぶ。 |
| D1 | 対戦チュートリアル1 | 対戦に必要な基本操作と考え方を学ぶ。 |
| D2 | 対戦チュートリアル2 | 最低限の対戦プログラムを作れる状態を目指す。 |
| E | 「かつ」 | 複数条件を組み合わせて判断する方法を学ぶ（あまり多く作れませんでした；；）。 |
| F1 | 変数：余りの分類 | 変数を用いて数や状態を分類する考え方を学ぶ。 |
| F2 | 変数：状態の切り替え | 変数で行動の状態を管理し、切り替える方法を学ぶ。 |
| F3 | 変数：周りを見る | 「まわりの◯番」を変数に記録して判断する考え方を学ぶ。 |
| G | ムズパズル | 対戦ではでないが、プログラミングで重要なパズル的思考を扱う。 |

D2までを終えることで、最低限の対戦を行うためのプログラムを作成できることを想定しています。

F以降は、変数を利用した状態管理や周囲の状況に応じた判断を扱います。これらは、今後登場するLOOKやSEARCHを理解・活用するための準備にもなります。

## 難易度の追加

各ステージには、難易度として星1から星15までの評価を設定しました。

現時点では、難易度はもやしによる感覚的な評価です。今後、実際に子どもや学習者がプレイした際のクリア率、試行回数、ヒント利用状況などを確認し、必要に応じて調整します。

---

## 「前と同じ向きに歩く」ブロックの削除

チュートリアル用ブロックセットから、**「前と同じ向きに歩く」ブロックを削除しました。**

このブロックは便利である一方、使い方によっては変数を使わずに多くの課題を解けてしまいます。その結果、変数を用いて方向や状態を記録・管理する学習機会が減ってしまうと判断しました。

そのため、変数を使った状態管理を学ぶステージでは、このブロックに依存しない構成に変更しています。

## 追加したステージ

### アイテム取得ステージ

アイテムを取得しながらゴールを目指すステージを追加しました。

単にゴールへ到達するだけではなく、周囲のアイテムを確認し、必要な行動を選ぶプログラムを考えることを目的としています。

### PUTステージ

PUTを学ぶためのステージを追加しました。

PUTの基本的な使い方を理解するためのステージに加え、実際の対戦に近い状況で使うステージも配置しています。
実戦形式のステージでは、HOTがランダムに行動します。

HOTの行動プログラムは、各ステージのレビューHTMLに記載しています。

### 変数を使うステージの再配置

もともと前半に配置していた変数関連のステージは、より後半へ移動しました。

また、もともとある簡単なステージを変数で解かせるというI先生のスライドを参考に、
変数以外で解けないようにブロックセットを調整し、簡単なステージを変数を使って解く内容を追加しています。

基本的な移動、条件分岐、アイテム取得、対戦の基礎を学んだ後で変数を扱うことで、変数が必要になる理由を理解しやすくすることを狙っています。

## クリア条件の追加

ステージのクリア条件として、以下を追加しました。

| クリア条件 | 内容 |
| --- | --- |
| `item{N}+goal` | N個以上のアイテムを取得してからゴールする。 |
| `defeatEnemy` | 敵を倒す。 |
| HOTを倒す、またはNターン後にアイテム数でHOTを上回る | 敵を倒すか、指定ターン終了時点でHOTより多くアイテムを所持する。 |

## 解答例・レビュー情報

解答が用意されているステージについては、解答プログラムのスクリーンショットをレビューHTMLに掲載しています。

また、PUTを扱う対戦ステージなど、HOTの行動が重要になるステージについては、HOT側の行動プログラムもテキストで確認できます。

詳細は、[チュートリアルステージ一覧・レビュー](./stage_review_v3.html) を参照してください。
